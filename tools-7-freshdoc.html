FreshDoc, a tool for automatically updating outdated API names in documentation

Overview

FreshDoc is a tool for automatically updating outdated API names in documentation. This source code of the tool will be released after the related paper is published. The FreshDoc tool and our evaluation results are available at https://figshare.com/articles/FreshDoc_Package_zip/7012220.
