# Software Evolution and Architecture Lab

연구실 홈페이지: https://selab-gnu.github.io/

기존 홈페이지(http://selab.gnu.ac.kr/index.php)의 공개 내용을 옮긴 GitHub Pages 사이트입니다.

## 페이지와 자료 수정

- 소개: `data/home.html`
- 논문 목록: `data/publications.json`
- 멤버, 수업, 도구 및 상세 페이지: `data/sections.json`
- 공통 화면: `scripts/build.py`
- 디자인: `styles.css`
- 논문 전용 검색: `site.js`
- 논문·강의 통합 검색: `search.js` / `search.html`

Python 3에서 `python scripts/build.py`를 실행하면 16개 HTML 페이지가 생성됩니다. 별도 패키지 설치는 필요하지 않습니다. 생성한 HTML도 함께 커밋하고 main에 push합니다.

로컬 미리보기: 저장소에서 `python -m http.server 8000` 실행 후 http://localhost:8000 접속.

## GitHub Pages와 인수인계

저장소 Settings → Pages에서 배포 설정을 확인합니다. 브랜치 배포를 사용할 때는 main / (root)를 선택합니다. `.nojekyll`은 HTML을 그대로 게시하도록 하는 파일입니다.

후임자에게 저장소 권한, Pages 설정, 자료 수정 및 빌드 방법을 전달하세요. 현재 실행에 필요한 서버 계정, API 키, npm 패키지는 없습니다.

로그인 영역은 준비 중 표시이며 인증 기능은 없습니다. PDF는 기존 링크를 유지합니다. 상세 이전 범위와 검수 결과는 `MIGRATION.md`를 참고하세요.

## 통합 검색

모든 공개 페이지 상단의 검색은 `search.html`로 이동합니다. 현재는 논문의 제목·저자·연도 등 서지정보를 검색합니다. 연구 분야(SE·AI·AERO·미분류)와 게재 유형(국제학술지·국제학회·국내학술지·국내학회)을 함께 선택할 수 있으며, 검색어 없이 필터만 선택해도 목록을 볼 수 있습니다. 검색 조건은 URL의 `q`, `tag`, `type`에 저장되어 새로고침·공유·뒤로 가기에서 유지됩니다. PDF·첨부파일 내부는 검색하지 않습니다.

논문은 저장소 자료를 먼저 표시한 뒤 Firestore의 최신 공개 자료를 반영합니다. 클라우드 확인이 실패하거나 6초를 넘기면 저장소 자료로 검색하고 화면에 안내합니다. Publications 본문에는 중복 검색창을 두지 않고, 논문별 분야 태그에서 검색 필터로 이동합니다. 변경 후 `python scripts/build.py`로 검색 페이지와 모든 공통 헤더를 함께 생성합니다. 검색 추가에는 Firebase 규칙 변경이 필요하지 않습니다.

`node scripts/test-search.cjs`로 Playwright 기반 모의 백엔드 검증을 실행합니다. Playwright 패키지 경로와 설치된 Chrome 경로는 필요하면 `NODE_PATH`, `TEST_BROWSER_PATH`로 지정합니다. 실제 Firebase에는 저장하지 않습니다.

## 논문 연구 분야 태그

관리자 논문 추가·수정 화면에서 SE·AI·AERO를 복수 선택합니다. 태그를 전부 해제하면 미분류로 저장됩니다. 기존 HTML 인용문을 `span[data-paper-tags]`로 감싸 저장하므로 Firestore의 groups/items 문자열 구조와 규칙은 바뀌지 않습니다.

`data/publication-tags.json`에는 현재 139개 항목의 태그·게재 유형·확인된 발표일을 기록합니다. 교수님 목록과 대응되는 138개는 출처의 태그를 유지했고, 기존 연구실에만 있던 1개는 제목·게재처를 근거로 SE로 분류했습니다. 명시적으로 저장한 태그가 초기 태그보다 우선하며, 빈 태그도 자동으로 되돌리지 않습니다. 2026-10-27에 누락 논문·발표 29개를 반영하여 총 139개입니다.

## 교수님 논문 목록 추가 반영 (2026-10-27)

`data/publication-imports.json`의 29개 항목을 기존 110개와 합쳐 `data/publications.json`에 139개를 저장했습니다. 기존 인용문은 변경하지 않았고, 추가 항목만 연도 순으로 삽입했습니다.

Firebase에 예전 110개 목록이 남아 있어도 공개 페이지·검색·관리자 화면은 같은 병합 함수를 사용해 추가 항목을 보여줍니다. 관리자가 공개 저장하면 각 group의 `publicationImports`에 배치 ID를 함께 저장합니다. 이 이력이 있으면 해당 배치를 다시 합치지 않으므로 이후 수정·삭제한 논문이 되살아나지 않습니다. 누락 항목만 보충하고 기존 클라우드 소개·멤버·논문 수정 내용은 보존합니다. 읽기 중에는 Firebase를 변경하지 않습니다. groups 안의 부가 메타데이터이므로 Firestore 규칙 변경은 필요하지 않습니다.

`node scripts/test-publication-imports.cjs`는 기존 클라우드 병합, 중복 방지, 기존 내용 보존, 삭제·수정 우선권, 검색 링크 일치를 모의 데이터로 확인합니다.

## 멤버 이메일 보완과 논문 날짜 정렬 (2026-10-27)

전달된 명부의 이름·이메일 열을 대조해 이메일이 비어 있던 6명만 `data/member-emails.json`에 반영했습니다. 원본 명부의 다른 개인정보는 가져오지 않았습니다. 고정 멤버 ID와 확인된 이름을 우선 사용하고, 기존 이메일·사진·자기소개는 유지합니다. 정적 멤버 페이지와 Firebase 멤버를 읽는 공개·관리 화면에 같은 보완을 적용합니다. 프로필을 개별 공개 저장하면 보완된 소개도 Firebase에 저장됩니다.

`data/publication-tags.json`의 139개 항목에 확인된 발표·게재일과 분류를 기록했습니다. 연도만 확인된 132개는 연도, 월까지 확인된 4개는 연·월, 일까지 확인된 3개는 연·월·일 기준으로 정렬합니다. 수상연도나 DOI URL의 숫자는 발표연도로 쓰지 않습니다. 기존 미분류 논문 1개는 제목과 소프트웨어공학 워크숍 게재처를 근거로 SE로 분류했고, 본문 근거 없는 AI 태그는 추정하지 않았습니다.

정적 생성·Firebase 목록 병합·검색·관리자 공개 저장에서 같은 날짜 기준을 사용합니다. 같은 날짜/정밀도의 항목은 기존 순서를 유지합니다. 새 논문의 월·일이 없으면 연도만 사용합니다.

## Google 로그인 창이 열리지 않을 때

기본 버튼은 Google 팝업 로그인을 사용하며, 대기 중 진행 상태와 차단·닫힘·네트워크 오류를 표시합니다. 팝업이 보이지 않으면 ‘현재 창에서 로그인’으로 이동 방식을 선택할 수 있습니다. 이동 후 로그인 결과를 받지 못하면 무한 대기하지 않고 다른 브라우저에서 팝업 로그인을 시도하도록 안내합니다. 앱 내 브라우저나 타사 저장소 차단 환경에서는 Chrome·Edge의 일반 탭을 사용하세요. 로그인 UI 보완은 기존 인증·권한 모듈을 공유하며 관리자·멤버·방문자 권한을 변경하지 않습니다.

제공받은 원본 PNG는 `assets/branding/`과 `assets/people/`에 보관합니다. `data/openlab.json`은 37장 발표자료에서 정리한 연구 분야 3개, 대표 연구 8개, 연혁 11개, 수상실적 17건과 근거 슬라이드를 담습니다. PPT 원본은 공개 저장소에 넣지 않습니다.

`scripts/build.py`는 공통 로고·메뉴, 홈 요약, `research.html`을 생성합니다. 한국어·영어 문구는 `i18n.js`와 `data/openlab.json`에서 관리합니다. 연구실 생활·수상 목록은 현재 관리자 편집 화면이 아닌 저장소에서 관리합니다. 변경 후 `python scripts/build.py`를 실행하세요.

교수님 기본 사진은 공개 화면·관리자 읽기에 함께 적용합니다. 기존에 별도로 저장한 사진을 덮어쓰지 않으며, 관리자에서 사진을 명시적으로 삭제하면 삭제 상태를 보존합니다. 새로운 사진 URL은 기존대로 HTTPS만 허용하고, 로컬 경로는 코드에 명시적으로 등록한 번들 사진만 허용합니다.

## 구성원 사진·이메일 수집 방지

추가로 제공받은 고성진·Kajal Patel·이의천 사진은 `assets/people/`과 `member-updates.js`에서 이름을 정확히 연결합니다. 번들 사진 경로는 `content.js`에서 개별 허용하며 임의의 로컬 경로는 허용하지 않습니다. 기존 사진 교체·삭제 선택은 유지합니다.

공개 화면의 이메일은 ‘이메일 보기’를 누를 때 주소와 메일 보내기 링크를 만들고, 다시 숨길 수 있습니다. 생성 HTML에는 원문 주소나 `mailto:` 대신 토큰을 넣습니다. Firebase에서 나중에 불러온 프로필과 홈 연락처에도 동일하게 적용합니다. 관리자 편집과 원본 자료는 원래 주소를 유지합니다.

이 방식은 단순한 주소 수집을 줄이기 위한 난독화입니다. 토큰은 암호화가 아니며 공개 데이터 JSON·기존 Firestore 읽기 권한을 변경하지 않습니다. 이미 수집된 주소의 스팸을 차단하거나 고급 수집기를 막는 기능은 아닙니다. 비공개 연락처가 필요하면 별도 서버에서 문의를 전달하는 구조가 필요합니다.

## 영어·한국어 버전 및 졸업생 목록

공개 페이지는 `?lang=en` / `?lang=ko`로 직접 열 수 있습니다. URL의 언어가 브라우저 저장값보다 우선하며 메뉴·연구 링크·검색 양식에도 언어를 전달합니다. 언어 선택 버튼을 누르면 본문과 주소를 함께 변경합니다.

`member-localization.js`는 확인된 이름 표기, 기존 연구 주제·소속·진출 정보의 번역을 관리합니다. Det Virak / Kajal Patel / Junho Lee 등 표시를 정리하며 원본 논문의 저자 표기는 바꾸지 않습니다. 새로 작성하는 임의의 자기소개를 외부 번역 서비스에 전송하지 않으므로, 새로운 문구의 양 언어 표현은 이 번역표에 추가해야 합니다.

졸업생은 `.alumni-list`의 간결한 행으로 표시하며 사진·이니셜·상세 펼치기 영역을 만들지 않습니다. 기존 기간·연구 주제·진출 정보와 원본 사진 데이터는 삭제하지 않습니다.

사용자가 삭제를 요청한 이연우 프로필은 공개·관리 목록에서 제외합니다. 정확히 지정한 기존 문서만 다음 관리자 멤버 자료 로드 때 트랜잭션으로 정리합니다. 공개 조회는 쓰기를 수행하지 않으며 계정 권한 문서는 변경하지 않습니다.

공개 이메일은 HTML에 아이디·도메인을 별도 조각으로 저장하고 JavaScript에서 `name@domain`으로 조합해 버튼 없이 표시하며 `mailto:` 링크를 만들지 않습니다. 현재 멤버의 프로필 상세도 접기 없이 바로 표시합니다. 이 표기는 단순 자동수집을 줄이며 원본 데이터에 대한 접근 제한이나 암호화는 아닙니다.

2026-11-03: 김태환·장혁은 현재 멤버 카드에서 제외하고 ‘졸업생 · 대학원 / Alumni · Graduate Students’의 사진 없는 목록으로 표시합니다. 교수님 포함 현재 표시는 11명이며 기존 졸업생 16명과 두 분의 프로필 원본은 보존합니다. PPT 28쪽의 석사 인원수(4명)와 나열된 이름(5명)이 달라 추가 이름은 임의 등록하지 않았습니다.

연구실 소개의 졸업생 진출 사례는 2026 오픈랩 PPT 30쪽의 21건을 `data/openlab.json`의 `careerOutcomes`에 기록합니다. 2026년 3건, 2025년 6건, 2024년 3건, 2023년 1건, 2022년 1건, 2018–2021년 7건이며 취업 20건·박사 진학 1건입니다. PPT의 연도 분류를 유지하며 현재 재직 여부나 정확한 입사일은 추정하지 않습니다. 현재 멤버 분류나 논문 저자 정보는 이 내역으로 변경하지 않습니다. 영문 이름은 확인된 기존 표기를 우선하고 없는 이름은 로마자 표기를 사용하므로 공식 선호 표기를 받으면 갱신할 수 있습니다.

졸업생 진출 사례는 기관별 13개 접이식 목록으로 표시합니다. 처음에는 모두 접혀 있으며 기업·기관명을 누르면 해당 이름과 PPT 분류 연도가 나타납니다. 21건을 보존하고 KT·KAI 사례는 KAI 안에 원문 소속을 함께 표시하며 박사과정 진학은 맨체스터대학교 항목에 표시합니다.

2026 오픈랩 원본 발표자료는 `assets/documents/2026-openlab.pptx`로 공개하고 PowerPoint에서 내보낸 37쪽 PDF(`2026-openlab.pdf`)와 표지를 함께 제공합니다. 연구실 소개 상단에서 PDF는 새 탭으로 열고 PPT는 다운로드합니다. 발표자료 본문은 한국어 원본이며 사이트의 언어 전환은 안내 문구에 적용됩니다. 원본 갱신 시 PDF·표지도 함께 갱신하세요.

2026-11-03 이메일 표시는 전달받은 코드 예시에 맞춰 JavaScript 조합 방식으로 변경했습니다. `data-email-user`와 `data-email-domain`에 각각 Base64로 저장하고 `textContent`로 주소를 조합합니다. Base64는 암호화가 아닙니다. 기존 단일 토큰도 읽으며 관리자 편집·저장에는 원래 이메일을 복원합니다. 정적 HTML의 완성 주소와 메일 링크를 줄이는 조치이며 공개 JSON·Firestore 및 공개 PPT/PDF 원본, JavaScript를 실행하는 수집기를 차단하지 않습니다.

네이버 로그인은 `NAVER-LOGIN-SETUP.md`의 앱·서버·규칙 설정 후 활성화합니다. 현재 빈 서버 설정에서는 준비 중 안내를 표시합니다. Google 권한과 네이버 UID 권한을 분리하며 이메일로 계정을 자동 병합하지 않습니다. 비밀키를 정적 홈페이지에 넣지 않습니다.
