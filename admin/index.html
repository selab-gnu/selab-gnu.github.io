기존 자료를 불러오는 중입니다…

계정 권한 관리

관리자는 논문·홈 소개·모든 멤버와 계정 권한을 관리합니다. 멤버는 연결된 본인 자기소개만 수정합니다. 방문자는 로그인 여부와 관계없이 공개 자료만 볼 수 있습니다.

공개 저장된 멤버를 Google 로그인 계정에 연결합니다. 표시용 이메일과 로그인 이메일이 달라도 연결할 수 있습니다. 멤버 권한에는 본인 소개 연결이 필수이며, 방문자에게는 편집 권한을 부여하지 않습니다.

    논문 수정

    원문의 저자·제목·연도·링크를 그대로 불러옵니다. 필요한 부분만 직접 수정하세요.

    저자 → 제목 → 학술지·학회 → 연도·권호·쪽 순으로 표기합니다. 선택한 분류의 맨 위에 추가됩니다. * 필수 입력

    공저자를 포함해 논문에 기재된 순서대로 입력하세요.

    논문 자료 연결 (선택)

    주소 없이 서지정보만 등록할 수도 있습니다. 파일은 업로드하지 않으며, 이미 공개된 자료의 주소를 연결합니다.

    입력하면 논문 제목에 링크가 붙습니다. 출판사·IEEE·MDPI·KCI·DBpia 등의 고정 주소를 권장합니다.

    별도의 (PDF) 링크로 표시합니다. 학회·연구실 서버 PDF나 누구나 열람할 수 있는 Drive 공유 주소를 입력하세요. 만료되는 임시 주소는 피해주세요.

    게시 표기 미리보기

    목록에 적용한 뒤 ‘홈페이지에 공개 저장’을 눌러야 게시됩니다.

    홈페이지 소개 내용

    소개, 연구실 원칙, 세미나 안내를 화면에서 직접 편집하세요.

    기존 멤버 자료 안내

    아래에서 바로 새 멤버를 추가하거나 기존 멤버를 수정·삭제할 수 있습니다. 첫 공개 저장 시 기존 전체 소개를 보관하고 멤버별 저장으로 함께 전환합니다.

    분리된 소개 미리보기

    전체 멤버 관리

    멤버를 선택하면 해당 소개만 수정합니다. 멤버 저장은 논문·홈 소개 저장과 별개로 공개 반영됩니다.

    선택한 멤버 수정

    기존 표기와 링크를 보존한 개인별 편집 영역입니다. 이름을 변경하면 기본 소개 안의 이름도 함께 수정해주세요.

    연결된 멤버는 이 자기소개만 직접 수정할 수 있습니다. 자기소개와 연락처 등 모든 내용은 공개됩니다.

    멤버 추가

    기존 Members 페이지처럼 이름, 직무·과정, 소속, 연락처, 연구 분야를 순서대로 표시합니다. 자기소개도 함께 작성할 수 있습니다. * 필수 입력

    기본 정보

    교수, 박사과정, 석사과정, 학부연구생 등 현재 상태를 입력하세요.

    소속·위치 (선택)
    연락처 (선택)

    이메일과 홈페이지는 공개 페이지에서 클릭할 수 있는 링크로 표시됩니다.

    연구·소개 (선택)

    줄바꿈은 게시 화면에서도 유지됩니다. 비워둔 항목은 표시하지 않습니다.

    멤버 소개 미리보기

    멤버 추가하기를 누르면 바로 공개 저장한 뒤 홈페이지의 멤버 소개로 이동합니다. 추가로 공개 저장 버튼을 누를 필요가 없습니다. 첫 등록 시 기존 자료는 보존하면서 멤버별 관리로 함께 전환합니다.

    내 자기소개

    최대 10,000자. 저장하면 공개 멤버 페이지에 반영됩니다.

    수정 내용 미리보기

    공개 사이트에 반영하기 전 내용과 배치를 확인하는 공간입니다.
