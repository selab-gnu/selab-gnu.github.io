# 공개 홈페이지 언어 버전·멤버 표시 수정

## 영어·한국어

공개 홈페이지의 홈, 연구실 소개, 멤버, 논문, 뉴스, 갤러리, 검색에서 선택한 언어를 유지합니다. `?lang=en`과 `?lang=ko`를 붙여 해당 버전을 직접 열거나 공유할 수 있습니다.

- 주소에 지정한 언어가 이전 브라우저 저장값보다 우선합니다.
- 메뉴·홈 안내·교수 소개·멤버 과정·프로필 상세·연구 주제·졸업생 진출 정보를 전환합니다.
- 연구실 소개의 학회명·진출 기관, 뉴스 출처 이름, 갤러리 버튼과 안내도 점검했습니다.
- 논문 제목·서지정보는 학술 원문을 유지합니다.
- 공개 사이트의 현재 소개 자료를 기준으로 번역했습니다. 향후 새로 작성하는 자기소개를 외부 번역 서비스로 자동 전송하지는 않습니다.

## 이름 표기

Det Virak, Kajal Patel, Junho Lee 등 이름의 표시를 정리했습니다. 확인된 한국어 이름을 사용하며 한국어 화면에는 필요한 경우 영문 이름도 함께 보여줍니다. 확인되지 않은 한국어 이름을 임의로 추정하지 않았습니다. 원본 데이터의 문서 ID나 논문 인용문 속 저자명은 바꾸지 않았습니다.

## 졸업생

기존 대학원 졸업생 9명과 학부 졸업생 7명, 총 16명의 기록을 유지합니다.

- 사진·‘사진 준비 중’·이니셜 공간 제거
- 이름, 과정·재학 기간, 연구 주제, 진출 정보 중심의 행 목록
- 긴 주소와 불필요한 카드·상세 펼치기 제거
- 기존 저장 자료와 사진 원본은 유지

현재 멤버의 사진·과정별 정렬과 교수님 우선 배치는 유지합니다. 사진 유무만으로 활동 여부를 판단하거나 현재 멤버를 졸업생으로 옮기지 않았습니다.

## 이연우 프로필

사용자의 명시적인 요청에 따라 공개·관리 목록에서 제외했습니다. 기존 원본 문서는 다음 관리자 멤버 화면 로드 때 정리하도록 했습니다. 정확한 문서 ID와 이름을 확인한 뒤 해당 프로필만 삭제하며 졸업생 기록이나 로그인 권한은 삭제하지 않습니다.

이 원본 정리는 Firebase 관리자 인증이 필요한 작업입니다. 공개 페이지의 익명 조회로 삭제를 시도하지 않습니다.

## 확인

- 실제와 같은 기존 클라우드 프로필을 이용해 언어별 본문 확인
- 영어 화면의 홈·연구실 소개·멤버·뉴스·갤러리에 남은 한국어 점검
- 멤버 상세와 연구 주제, 한국어 졸업생 진출 정보 확인
- 16명 졸업생의 사진 영역이 없는지 확인
- 공개 조회에서 원본 삭제가 발생하지 않는지 확인
- 지정 프로필만 관리자 정리 대상이 되는지, 반복 정리가 안전한지 확인
- 언어별 링크·검색·새로고침 및 390/768/1440px 표시 확인

배포 여부와 공개 링크는 최종 작업 메시지에서 안내합니다.
