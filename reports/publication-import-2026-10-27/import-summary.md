- 저자·제목·게재처·연도·SE/AI/AERO 태그를 출처대로 옮겼습니다.
- DOI가 있는 항목은 DOI, 없는 항목은 교수님 사이트의 해당 논문 항목으로 연결했습니다. 출처에 없는 PDF 주소는 만들지 않았습니다.
- 같은 연구 주제여도 학술지·학회 발표가 다른 항목은 각각 보존했습니다.
- 1999–2015년의 과거 항목도 포함되어 기존의 “2016년 이후만 기재” 문구를 수정했습니다.
- Firebase 공개 목록(revision 2, 110개)은 읽기만 했고 서버에 직접 쓰지 않았습니다.
- 코드 배포 후 공개 화면·검색·관리자는 추가 배치를 합쳐 139개를 표시합니다. 관리자가 공개 저장하면 그룹별 반영 이력도 함께 저장됩니다. 이력이 저장된 뒤의 관리자 수정·삭제는 추가 배치보다 우선합니다.
- 기존 데이터 형식의 groups 내부 메타데이터를 사용하여 Firestore 규칙 변경은 필요하지 않습니다.
