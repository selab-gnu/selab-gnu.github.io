# 연구실 홈페이지 개선 내역 — 2026-11-03

## 적용 범위

기존 GitHub Pages 홈페이지의 소스에서 작업했습니다. 네이비·청록 색감과 기존 Firebase 인증·권한 구조를 유지했습니다. 실제 Firebase 자료·규칙은 이 작업에서 직접 변경하지 않았습니다.

추가 답변에 따라 **개인 사진, 공식 로고, PPT를 바탕으로 한 수상실적 정리는 보류**했습니다. 또한 **Full-Time / Part-Time 구분은 제외**했습니다.

## 1. 교수님 소개

- 홈에 이선아 교수 소개 패널을 추가했습니다.
- 소프트웨어공학과·AI융합공학과, 주요 연구 분야, 개인 홈페이지, 대학 공식 소개, 대학 이메일을 표시합니다.
- 주요 연구는 소프트웨어 진화·아키텍처, 소프트웨어공학을 위한 AI, 자율비행·안전성 분석으로 간결하게 정리했습니다.
- 멤버 페이지의 교수 카드에도 소속과 소개를 표시하며 교수님을 맨 위에 배치했습니다.
- 사진을 받은 것으로 표시하지 않도록 이니셜을 사용했습니다. 공식 로고 파일도 임의 제작·대체하지 않았습니다.

확인 출처:

- [교수님 개인 홈페이지](https://saleese.github.io/)
- [경상국립대학교 소프트웨어공학과 교수소개](https://www.gnu.ac.kr/soft/pi/prfsr/selectPrfsrIntrdView.do?mi=14189)

기존 홈의 오래된 인원 수와 “공사 중” 문구는 제거했습니다. 운영 원칙과 연구실 위치는 정리하고, 기존 세미나 안내는 유지했습니다. Firebase에 이 오래된 “공사 중” 소개가 남아 있으면 새 기본 소개를 표시하고, 다른 별도 편집 내용은 유지합니다.

## 2. 각 사람 사진 — 자료 수령 후 진행

사진이 있는 기존 프로필은 그대로 표시하고, 없는 프로필은 이니셜과 ‘사진 준비 중’으로 표시합니다. 사람별 사진 영역의 크기를 통일했습니다.

기존 관리자 화면의 JPG·PNG·WebP 등록, 자동 축소, 사진 교체·삭제 기능을 유지했습니다. 자료가 없는 사람의 사진을 검색 결과에서 추정하거나 다른 사람의 사진으로 채우지 않았습니다.

## 3. 멤버 정렬·수평 배치

현재 멤버는 다음 순서로 표시합니다.

1. 교수
2. 박사과정
3. 석사과정
4. 학부연구생
5. 기타 멤버 — 과정이 기존 소개에 없는 경우
6. 대학원 졸업생
7. 학부 졸업생

Full-Time / Part-Time 제목과 표시는 제외했습니다. 기존 저장 자료 자체는 불필요하게 삭제하지 않았습니다.

- 넓은 화면에서는 학생을 3열, 중간 화면에서는 2열, 휴대폰에서는 1열 카드로 표시합니다.
- 교수님은 별도의 넓은 카드로 표시합니다.
- 카드에는 이름·과정·이메일·연구 주제·자기소개를 보여주고, 긴 주소와 원래 소개는 ‘프로필 상세’를 열어 확인합니다.
- 같은 과정 안에서는 기존 드래그 순서를 유지합니다. 과정이 다른 사람을 드래그해 정렬 규칙을 깨는 것은 막고, 이유를 안내합니다.
- 새 멤버는 해당 과정·구분의 마지막에 들어갑니다.

## 4. 이의천 연구 주제

다음 5개로 수정했습니다.

- Autonomous Flight
- Deep Reinforcement Learning
- 3D CAD Automation
- System/SW Safety Analysis
- Aircraft Simulation

저장소의 기본 소개를 수정했으며, Firebase에 예전 ‘Reinforcement Learning’만 있는 경우에도 공개 화면과 관리자 읽기 단계에서 같은 내용을 보완합니다. 이후 관리자가 다른 주제로 수정한 내용은 다시 덮어쓰지 않습니다. 기존 멤버 문서의 자동 저장이나 권한 변경은 하지 않았습니다.

## 5. 영어·한국어 선택

공개 페이지 상단에 **EN / 한국어** 버튼을 추가했습니다.

- 홈, 멤버, 논문, 뉴스, 갤러리, 논문 검색에서 공통으로 보입니다.
- 선택한 언어를 브라우저에 저장해 페이지 이동·새로고침 후에도 유지합니다.
- 메뉴, 제목, 홈 소개, 교수 소개, 멤버 과정·프로필 안내, 논문 필터, 검색 안내와 추가한 6건의 뉴스 요약을 전환합니다.
- 문서의 언어 속성도 함께 변경합니다.
- 논문 제목·서지정보, 이름, 멤버 작성 자기소개, 기존 관리자가 작성한 게시물은 원문을 유지합니다. 자동 번역으로 학술정보를 바꾸지 않습니다.
- 관리자 편집 화면은 기존 한국어 UI를 유지했습니다.

## 6. 수상실적 — PPT 수령 후 진행

PPT에 있는 상의 이름·연도·수상자·사진은 아직 확인하지 않았으므로 수상실적 전체 목록을 만들지 않았습니다. 다만 뉴스 항목에서는 대학 공식 보도로 확인된 수상 소식을 소개했습니다. 이 뉴스와 PPT 기반 수상실적 전체 정리는 별개입니다.

## 8. Publications 복합 필터·편수 표시

검색창을 다시 추가하지 않고 다음 선택 필터를 마련했습니다.

- 연도
- 특정 저자
- 학술지·학회
- 연구 분야: SE / AI / AERO / 미분류

여러 조건은 교집합으로 적용합니다. 예를 들어 ‘2025년 → Uicheon Lee / 이의천 → Drones’를 선택하면 해당 논문 1편을 볼 수 있습니다.

- 각 선택지 옆 숫자는 전체 자료에서 해당 조건에 해당하는 편수입니다.
- 결과 요약은 ‘전체 139편 중 N편 표시’로 보여줍니다.
- 분류별 제목과 이동 버튼에는 해당 분류의 편수를 표시합니다. 필터를 적용하면 ‘현재 편수 / 분류 전체 편수’가 됩니다.
- 결과가 없는 분류는 목록에서 숨기고, 전체 결과가 없으면 안내 문구를 보여줍니다.
- 필터 선택은 URL에 반영되어 새로고침과 링크 공유 후에도 유지됩니다.
- 개별 논문 링크를 열었을 때 필터 때문에 그 논문이 가려지면 필터를 해제해 보이게 합니다.
- 필터 초기화 버튼은 모든 논문을 다시 보여줍니다.
- Firebase 최신 논문이 로드되면 선택지와 편수도 함께 갱신됩니다.

학술지 약어·권호·학회 회차가 달라도 같은 게재처는 묶도록 표기를 정리했습니다. 확인 가능한 한글·영문 저자명도 연결했습니다. 원문이 이니셜만 제공하고 같은 인물이라고 확인하기 어려운 경우에는 임의로 합치지 않았습니다. 추가 논문은 서지정보에서 필터 자료를 추출하므로 새 표기 방식이 들어오면 정규화 규칙 보완이 필요할 수 있습니다.

## 검증·검토

Chrome에서 데스크톱 및 휴대폰 너비로 검증했습니다. 검증은 모의 Firebase 자료를 사용했고 실제 서비스에 시험 자료를 쓰지 않았습니다.

- 신규 공개 UI: 복합 필터, 결과 수, 초기화, URL 복원, 언어 유지, 멤버 과정별 정렬, 교수 우선, 연구 주제, 6건 뉴스
- 기존 논문 검색: 검색 결과 링크, 분야·유형 필터, XSS 처리, 클라우드 자료 및 오프라인 대체
- 기존 논문 병합: 추가 29편 및 전체 139편, 순서, 중복 방지, 기존 편집·삭제 보존
- 멤버 이메일: 빈 이메일 보완, 기존 이메일·사진·자기소개 보존
- 로그인: 팝업 진행·차단·닫힘·대체 로그인·오류 복구
- 전체 관리자 기능: 멤버·논문·뉴스·갤러리 관리, 자기소개 권한, 드래그 순서, 사진 교체·삭제, 충돌·저장 실패 복구

미리보기 주소는 실행 중인 이 컴퓨터에서만 사용할 수 있습니다. 공개 GitHub Pages 반영 여부는 최종 작업 메시지에 별도로 안내합니다.
